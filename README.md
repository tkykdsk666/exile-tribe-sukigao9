# EXILE TRIBE 好き顔9選

这是一个可直接部署到 GitHub Pages 的静态网页。

## 当前版本
- 两两比较
- Elo Rating
- 200 / 400 次比较
- 「两个都喜欢」「跳过」「返回」
- 最终输出 TOP 9
- 图片只在浏览器本地处理，不上传服务器

## 使用
1. 打开网页。
2. 在名单框中填写完整成员名单，每行：
   `团体｜姓名`
3. 按名单顺序一次选择对应照片。
4. 选择比较次数并开始。

## GitHub Pages
建立一个公开 GitHub repository，把 `index.html` 上传到根目录。
进入 Settings → Pages → Deploy from a branch → 选择 `main` / root。
等待部署后，GitHub 会生成一个 `https://用户名.github.io/仓库名/` 地址。

注意：本项目没有内置艺人照片。公开发布前请确认照片的使用权限；建议使用你自己制作或获得授权的头像素材。
