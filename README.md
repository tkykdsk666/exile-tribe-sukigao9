# EXILE TRIBE 好き顔9選

EXILE TRIBE現行85名を対象に、2人ずつ比較してEloレーティングで「好き顔 TOP9」を算出するファン制作ページ。

## ファイル
- `index.html`：画面・日英切替・比較ロジック
- `members.json`：85名の名前・所属・写真URL
- `README.md`：説明

## GitHub Pages
3ファイルを同じ階層に置き、GitHub Pagesを有効にしてください。

## 編集
- 説明文・ボタン・英訳：`index.html` の `const T`
- メンバー名・所属・写真：`members.json`

## 仕様
- 85名
- サクッと版：200回
- じっくり版：400回
- Eloレーティング
- 「どちらも好き」「スキップ」「ひとつ戻る」
- 途中経過をブラウザに保存
- JP / EN
- スマートフォン対応
- 兼任メンバーは1人につき1回
- 兼任EXILEメンバーは主要グループ側の写真を使用
